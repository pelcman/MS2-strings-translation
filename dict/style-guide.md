# 表記スタイルガイド

既存 JMS2 訳(corpus)から抽出した表記ルール。新規翻訳はすべてこれに従う。

## 記号・数字

| 項目 | ルール | 例 |
|---|---|---|
| コロン | 全角「：」スペースなし | `称号：優しい花嫁` `撮影チケット：神秘の宝島` |
| 括弧 | 半角 `()`、前後スペースなし | `服(上)(女)` `タイレンコンバットブーツ(レンジャー)` |
| 数字・英字 | 半角 | `70レベル` `(LV70)` `MK-II` |
| スラッシュ | 半角 `/` | `帽子/グローブ/靴選択ボックス` `(LV70/武器)` |
| 中黒・長音 | 既存訳の表記を踏襲(勝手に変えない) | `ルミ・ド・マギア` |
| 行頭接頭辞 | `(〜) ` 後ろに半角スペース1つ | `(ネットカフェ) ` `(景品) ` `(入門用) ` |

## 定型パターン

- 性別: 名前末尾に `(女)` / `(男)`(元: (F)/(M)/(Female)/(Male)/(여)/(남))
- 職業: 名前末尾に `(ナイト)` など。所有格 `Knight's X` は `X(ナイト)` に変換
- レベル: 括弧内は `(LV70)` `(LV50/武器)`。接頭なら `70レベル〜`
- 欠片: `〜の欠片`(装備・ボックス由来)/ `〜の破片`(素材・鉱物由来)
- 上下服: `〜服選択ボックス(上下)` `〜服ランダムボックス(上下)`
- ランク報酬: `{コンテンツ名}{S+|S|A|B|C}ランク報酬ボックス`

## 文体・トーン(アイテム名)

- 名詞句で簡潔に。カタカナ複合語は区切りスペースなしで連結(`タイレンオフィサーサークレット`)
- 擬態語は既存訳の雰囲気に合わせる: ぽっちゃり/もこもこ/ふかふか/きらりん/ドタバタ など
- 直訳が不自然な場合は日本の慣用語彙を使う(例: 답례품→引き出物、광물수레→鉱石トロッコ)

## UI・ストーリー翻訳時の追加ルール(今後の作業向け・随時更新)

- `{0}` `%s` `<b>` などのプレースホルダー・タグは**絶対に保持**する(検証スクリプトで数を照合)
- 改行(`\n`)・制御文字は元データと同数を保つ
- 会話文は話者の口調を統一する(話者別口調表は今後 `dict/characters-voice.md` に整備予定)
- システムメッセージは「です・ます」調、フレーバーテキストは文脈に応じて常体可
- 既訳のクエスト名・地名・スキル名が UI に再登場する場合は corpus / 本辞書で照合してから訳す
