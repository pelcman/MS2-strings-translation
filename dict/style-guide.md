# 表記スタイルガイド

既存 JMS2 訳(corpus)から抽出した表記ルール。新規翻訳はすべてこれに従う。

## 記号・数字

| 項目 | ルール | 例 |
|---|---|---|
| コロン | 全角「：」スペースなし | `称号：優しい花嫁` `撮影チケット：神秘の宝島` |
| 括弧 | 半角 `()`、前後スペースなし | `服(上)(女)` `タイレンコンバットブーツ(レンジャー)` |
| 数字・英字 | 半角 | `70レベル` `(LV70)` `MK-II` |
| スラッシュ | 半角 `/` | `帽子/グローブ/靴選択ボックス` `(LV70/武器)` |
| 中黒・長音 | 既存訳の表記を踏襲(勝手に変えない) | `ルミ・ド・マギア` |
| 行頭接頭辞 | `(〜) ` 後ろに半角スペース1つ | `(ネットカフェ) ` `(景品) ` `(入門用) ` |

## 定型パターン

- 性別: 名前末尾に `(女)` / `(男)`(元: (F)/(M)/(Female)/(Male)/(여)/(남))
- 職業: 名前末尾に `(ナイト)` など。所有格 `Knight's X` は `X(ナイト)` に変換
- レベル: 括弧内は `(LV70)` `(LV50/武器)`。接頭なら `70レベル〜`
- 欠片: `〜の欠片`(装備・ボックス由来)/ `〜の破片`(素材・鉱物由来)
- 上下服: `〜服選択ボックス(上下)` `〜服ランダムボックス(上下)`
- ランク報酬: `{コンテンツ名}{S+|S|A|B|C}ランク報酬ボックス`

## 文体・トーン(アイテム名)

- 名詞句で簡潔に。カタカナ複合語は区切りスペースなしで連結(`タイレンオフィサーサークレット`)
- 擬態語は既存訳の雰囲気に合わせる: ぽっちゃり/もこもこ/ふかふか/きらりん/ドタバタ など
- 直訳が不自然な場合は日本の慣用語彙を使う(例: 답례품→引き出物、광물수레→鉱石トロッコ)

## UI・ストーリー翻訳時の追加ルール(今後の作業向け・随時更新)

- `{0}` `%s` `<b>` などのプレースホルダー・タグは**絶対に保持**する(検証スクリプトで数を照合)
- 改行(`\n`)・制御文字は元データと同数を保つ
- 会話文は話者の口調を統一する(話者別口調表は `dict/proper-nouns.json` の `speaker_voice` を参照)
- システムメッセージは「です・ます」調、フレーバーテキストは文脈に応じて常体可
- 既訳のクエスト名・地名・スキル名が UI に再登場する場合は corpus / 本辞書で照合してから訳す

## 敬称・タグ(会話データ翻訳の必須ルール)

`scriptquest` / `questdescription_final` などの会話・説明文を訳すときは以下に必ず従う。
根拠はいずれも JMS2 公式原本(`json_weblate/jp/*.json` の既訳)の実測値。

| 項目 | ルール | 根拠 |
|---|---|---|
| プレイヤー | `$MyPCName$님` → **`$MyPCName$さん`** | 公式原本 486件・「様」0件 |
| NPC | NPC名タグ + `님` → **`$npc:...$様`** / `$npcName:...$様` | 公式原本 様243件・さん1件 |
| NPC(例外) | KO が `씨` `형` など `님` 以外なら → **さん** | 公式が「さん」を使う |
| 役職 | `여제(님)`→女王(様) / `총리`→大臣 / `함장님`→艦長 / `부장님`→部長 | 命名系ファイル(npctitle 等)優先 |

- タグと敬称の間にスペースは入れない(`$npcName:X$$npcTitle:X$様`)。
  KO 側に `$npcName:X$ $npcTitle:X$님` とスペースがあっても日本語では詰める(タグ集合は不変)。
- **韓国語の助詞タグ `$pp:를,을$` `$pp2:로,으로$` `$ppr:...$` はすべて削除**し、日本語の助詞を直接書く。
  タグ削除で生じた不自然な二重スペースは詰める。
- 敬称・語尾・一人称の話者別設定は `dict/proper-nouns.json` の `speaker_voice`、
  種族・キャラ固有の語尾は `dict/terms.json` の `speech_quirks` を参照。

## 記号(会話データ)

| 項目 | ルール | 根拠 |
|---|---|---|
| 感嘆符・疑問符 | **全角「！」「？」**。半角は英数字の直後のみ可 | 公式原本の約9割が全角(！5620/! 663、？4801/? 226) |
| 波ダッシュ | **U+301C「〜」**(U+FF5E「～」は使わない) | 本プロジェクトの統一表記 |
| 引用符 | KO の `'…'` `"…"` はすべて **「…」** | scriptquest / questdescription_final の既訳 |
| 引用符(例外) | アイテムタグの列挙 `'$item:…$', '$item:…$'` は**原文どおり `'…'` のまま** | 公式訳 207142514003923 ほか |
| 列挙のカンマ | 本文中は **「、」**。ボス名の羅列は公式訳の系列に合わせて `, ` のままの場合もある | questdescription_final 73000013 ほか |
| 三点リーダ | ASCII `...` は **「…」**。`…….`(6点+ピリオド)は **「……。」** | 既訳の慣例 |
| コロン | 全角「：」スペースなし(会話中の `코드명: X` も同様) | style-guide 冒頭の規則を踏襲 |
| 外国人名 | 姓名の区切りは中黒「・」(例: フィア・ド・カルロ、ウェイ・ホン、カール・ビドブライム) | npcname 既訳 |

- **KO 原文の行頭・行末の半角スペース、末尾の空行、タブ、`<font>` タグの開閉位置は
  そのまま維持する**(組み立て時に KO から機械転写して照合するのが安全)。
  行**中**の二重スペースは日本語では1つに詰めてよい(体裁上のものなので)。
- 原文のタグバグ(閉じられていない `<font>`、`$map:` の 0 埋め欠落、壊れたタグ片など)は
  **改変せず原文どおり維持**する。

## 文字集めイベントのアイテム

「1文字ずつ集めてフレーズを完成させる」タイプのイベントアイテム(`글자 아이템` 等)は、
**意味で訳さず原文の文字を1文字=1文字で維持する**。

- 中国語(簡体字)原文は対応する日本漢字に1対1で置換する
  (例: `冒险岛春暖花开` → `冒険島春暖花開`、`冒险岛喜迎新春` → `冒険島喜迎新春`)。
- クエスト名や説明文の中で当該アイテムに言及する場合は、
  **itemname の公式訳の文字をそのまま連結**する(意訳するとプレイヤーが集めるアイテムと紐づかない)。
- ハングルのフレーズは、対応する itemname の公式訳が壊れている場合でもそちらに合わせる
  (例: 30000589-30000596 の「神/し/い/メ/イ/プル/祝/第」)。
