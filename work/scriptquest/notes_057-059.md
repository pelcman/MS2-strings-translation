## 話者ごとの口調(先行/公式訳に準拠)

- **ジュンタ(준타)**: 厳格な男性。一人称「私」、PC を「お前」、「〜だ/〜ならん/〜のか/〜しろ」。
  公式 jp/scriptquest のジュンタ訳(「その通りだ。お前が持つエニマルはそもそもお前のものじゃないからだ」)に準拠。
- **ティンチャイ(틴차이)**: 気さくな女性の姉弟子。一人称「私」、PC を「君」、「〜だよ/〜ね/〜の」。
- **ラオズ(라오즈)**: 老師。**わし/おぬし/〜のじゃ/〜じゃろう**。
  公式 jp/scriptquest「試練はわしらを1つにしてくれる…おぬしだけでなく」に準拠。
- **ヴィジョン(비전)**: 柔らかい中性的な常体。PC を「お前/君」、「〜だよ/〜ないで/〜なきゃだめ」。
  公式(LapentaFrontier)訳「ムナクラの封印解除は成功したよ。その力も…君を認めたみたい。」に準拠。
- **タイクン(어흥이)**: 粗野な男性。一人称「俺」、PC を「お前」。先行 sq_map(###3152-3153)準拠。
- **フレイ(프레이)**: 近衛隊長。PC を「君」、「〜だな/〜してくれ/〜たまえ」。先行 sq_map(###3158-4508)準拠。
- **マーク / ボギー / ソルベイ**: 丁寧語、PC を「$MyPCName$様」。先行 sq_map 準拠。
- **情報員B(미어캣)**: 語尾 **다미→だミ / 다융→だユ / 냐미→かミ / 다미융→だミユ**。一人称「僕」。
  公式 jp/scriptquest のカルカルアイランド・ミーアキャット訳に準拠。
- **情報員M(카멜레온系)**: 冷静な常体、一人称「俺」。
- **謎の怪人**: 「我々」「お前」の硬い常体。
- **小屋のおじいちゃん**: わし/〜じゃった/〜おってな の老人語。

## 訳出上のメモ(原文の特徴)

- **###5798** の KO は `<font color="#909090">(…생각에 잠긴 모습이다.</font>` と**閉じ括弧が欠落**した原文。
  訳文でも原文どおり閉じ括弧なしで出力した。
- **###5836** の KO は「아니면 아닌 거지 ⏎」と**句点が無いまま行末スペース+改行**。原文どおり維持。
- **###5647** は KO が「…… 」(三点リーダ2つ+行末スペース)のみ。日本語も「…… 」とした。
- **###5613/5614** は 어흥이 が自分自身を `$npc:11000003$`(=タイクン)タグで呼ぶ台詞。タグをそのまま維持。
- **###5732/5744** の「시크릿 파일 0077. 무나크라 」は末尾スペース付き。維持。
- **###5773** の「독액이 흐르는 동굴」は map タグではなく生テキストなので、mapname 52000037 の
  既訳「毒が流れる洞窟」を直接埋め込んだ。同様に **###5671** の生テキスト「준타 사형」→「ジュンタ先輩」。
- 原文の行末スペース(計約80行)はすべて訳文でも同じ位置に維持している(自動照合済み)。
