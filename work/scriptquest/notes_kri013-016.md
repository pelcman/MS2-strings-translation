## 訳出上のメモ(原文の不整合・要注意点)

- **###41 `그래도 대행인 건`** は `그래도 다행인 건`(幸いなのは)の誤字。意味を取って「それでも幸いなのは」と訳出。
- **###59 `추가해야 할 일`** は `추구해야`の誤字。「追い求めるべき仕事」と訳出。
- **###75 `감사헤요`**(=감사해요)、**###98 `긴급 임부`**(=임무)、**###127 `간락하게`**(=간략하게)、
  **###134 `긴급 입무`**(=임무)、**###301 `말씀드릴 것`**(=말씀드린 것)、**###343 `기억나는 데로`**(=대로) は原文の誤字。
  いずれも意味を取って訳出。
- **###101 は原文に余分な句点**:「`$map:02020006$</font>에서 .스카이 포트리스의`」。**訳文では句点を落として**
  「〜で、スカイフォートレスの物品を盗む〜」とした(タグではないので改変扱いにしない)。
- **###377 `에네르 선점이 계속된`** は `계속되면`の脱字。「先取りが続けば」と訳出。
- **###103 は文末に句点がない**(「…생각하고 계신가 봐요⏎」)。**###118 も文末句点なし**。訳文でも句点を付けずに改行/終端した。
- **###237/238**:「탐사선을 격추하는`<font…>`」と `하는` と font タグの間にスペースがない。訳文は自然な形で連結。
- **###264/265**:「$MyPCName$님께서  $map:02020008$」と**2連スペース**。訳文では日本語の慣行に合わせて詰めた
  (行頭・行末の空白のみ原文どおり維持する方針)。**###125/194** の「가서  <font」も同様。
  そのため ###125/194 と ###142(1スペース版)は訳文が同一になるが、キーは別なので問題ない。
- **###204**: 汚染物質を食べるのは公式 94000200 では `$npcName:25021102$` だが、原文は `$npcName:23001006$` を主語にしている。
  **タグを改変せず**原文どおり訳した。
- **###319/324/325/328/329**: `<font>` タグの内側に「, 」やタグ間の空白が入っている(例
  `<font…>$map:02020034$, $map:02020013$</font>지역`)。**タグ位置は原文どおり**、区切りは全角「、」にした。
- font タグ無しの `$map:`/`$item:`/`$npcName:` 混在(###66/86/87/90/92/121/130/147/181/195/205/212/235/247/
  248/263/264/265/266/271/272/276/292/293/294/296/297/301/303/304/305/306/309/316/317/331/381/384/386 ほか)は
  **原文どおりタグ無しで維持**。
- 「...」(半角3点)は既存訳の慣例に従い「…」に統一(###21/34/49/253/291/339/385)。
  **「….」(3点+句点)は「…。」**(###278/338。notes_039-041 の「…….」→「……。」に整合)。
- 行頭・行末スペース(###26/31/43/49/52/67/68/69/75/91/92/99/105/125/126/142/156/160/164/175/194/212/223/230/
  232/234/248/275/284/317/338/352/356/376/382/386/396)、**行頭改行(###143)**、**行末改行(###180/242)**は
  すべて原文どおり維持。`_kric2_build.py` で全400行の行頭・行末空白と改行数・タグ集合を機械照合済み。
- `'…'`(KO の単引用符)は公式(94000043)に合わせ**「」**にした(###52/89)。
