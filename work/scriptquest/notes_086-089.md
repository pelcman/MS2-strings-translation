## 公式訳が割れていた箇所とその裁定

- **장물아비 → 故買屋**。questdesc 20001373 のみ「故買**商**」、questdesc 10001021・50001559 と
  scriptquest 原本 519030511005634 は「故買**屋**」。原本多数派 + 先行 sq_map063(2件) と
  `jp/scriptquest.json`(3件)がすべて「故買屋」なので **故買屋** を採用。
  **`glossary.tsv` の「장물아비=故買商」とは食い違うので glossary の修正を推奨。**
- **숲의 정기**: itemname 30000314 は「森の**オーラ**」、questdesc 10002510 と
  scriptquest 原本 831174302003626 は「森の**精気**」。本担当では常に `$item:30000314$`
  タグで出るため値には現れず、影響なし。
- **만데가솔**: itemname 20000057「マンデ**カ**ソール」vs questdesc 20001130「マンデ**ガ**ソル」。
  こちらもタグ出力のため値には現れない。
- **그리핀 / 그리폰**: KO 側で綴りが分かれており、公式も questdesc 50001505=グリ**フィン**種族、
  npcname 23000019・questdesc 10002521=グリ**フォン**。**原文の区別をそのまま反映**した
  (###8530-8532=グリフィン種族、###8626/8630=グリフォン)。
- **어둠의 땅**: scriptquest 原本 831174302003538 は「シャドウワールド」と意訳しているが、
  questdesc・achievedescription の多数派と notes_082-085 の確定に従い **闇の地**。
  別語の **쉐도우 월드** は **シャドウワールド**(questdesc 10002200)。
- **TELI**: 本文の生 ASCII「TELI / TELI_A / TELI_B」を npcname 公式の
  **テレポッド / テレポッドA / テレポッドB** に置換した(命名系最優先)。原文どおり
  ASCII を残す選択肢もあるが、NPC ネームプレートと一致させることを優先。
