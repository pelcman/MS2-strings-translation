## 訳出上のメモ(原文の不整合・判断)

- **###6190** の KO は `$npcName:11000075[gender:1]$ $npcTitle:11000075[gender:1]$님의` の語順
  (エレヴ 女王様)。日本語では「女王エレヴ様」が自然なため **タグの順序のみ入れ替えた**
  (`$npcTitle:...$$npcName:...$様`)。タグの追加・削除はなし。
- **###5929** の KO は `"…"` の二重引用符。style-guide に従い「」に変換した。
- **###6093** の KO は「엄청나게 $item:30000357$로군!」で、形容詞「낡은(古びた)」がアイテムタグの中に
  含まれるため直訳すると重複する。「これはまた、ずいぶんな$item:30000357$だね！」と意訳した。
- **###6082** は `<font color="#ffd200">` の開きタグと `</font>` が改行をまたいでいる原文。そのまま維持した。
- **###6001** の KO は `<font color="#ffd200">$item:30000151$?</font>` と「?」が font タグの内側にある。
  原文どおり維持した。
- **###6136** の「웅크린 엉덩이」は生テキスト(タグではない)なので npcname 既訳「ほらふきじじぃ」を直接埋め込んだ。
  **###6119** の「나메드 님」も同様に「ナメッド様」を直接埋め込んでいる。
- **###5905** の `$map:3000103$`(地獄の樹)・`$map:2000228$`(守護軍連合本部特別対策室)は
  他のタグと違い先頭 0 のない ID だが、原文どおりのまま維持した。
- 原文の行末スペース(2連スペースを含む ###5922/6151/6188 ほか、103 エントリ・計 151 行)は
  **スクリプトで機械的に KO と一致させて検証済み**(trailing/linecount mismatches: 0)。行中の2連スペース
  (###6007「이  」/ ###6034「건  할」/ ###6151「가진  」)は体裁上のものなので JA 側では1スペース
  または詰めた(キー側は原文どおり完全保持)。
