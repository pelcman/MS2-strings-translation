## 口調

- **블리체**(ブリーチェ/艦長): notes_kri001-004 を踏襲し常体・軍人口調。
  - PC の呼称は KO に合わせて訳し分け: `귀관` → **貴官** / `대원` → **隊員**(「$MyPCName$隊員」)
    / **`자네` → 「君」**(###272/278 のみ。KO がくだけた場面で 자네 に切り替わるため)
  - `수고했다` / `수고 많았다` → **「ご苦労だった」**(sq_kri004 の既訳に統一)
    `고생 많았다` / `고생했다` → **「苦労をかけたな」**(上と訳し分け)
  - `~하도록` → 「〜するように」、`~해라/~해줘라` → 「〜しろ/〜してこい」(命令の強さを反映)

  言いかけて詰まった表現なので「ラ…」と音のまま残した。

## 訳出上のメモ(原文の不整合・要注意点)

- **###31 は原文のタグが誤り**: 「검은군단의 기계 병사들이 `$map:25020002$`$pp:를,을$ 파괴」。
  25020002 は npcName の ID(###33/35 では `$npcName:25020002$`)だが、**タグを改変せず
  `$map:25020002$` のまま維持**した(原文バグ。###3 の対応箇所は `$map:02020029$`)。

- **###386/387 の `$pp:가,이가$` は不正な助詞タグ**(正しくは `$pp:가,이$`)。他と同様に削除。

  意味を取って「〜にハッキングされた」「〜がハッキングした」と訳し分けた(公式 94000014 に準拠)。
- ###37 の「$npcName:11004395$의 시민들」は文脈上 $map:02020030$(ゲオルクの街)の市民だが、
  タグを改変せず「マルレーネの市民たち」と直訳した。

  すべて原文どおり維持(`_kri_verify_b.py` で全行の行頭・行末空白と改行数を機械照合済み)。
