# scriptquest バッチ082-085 (###8096-8495) 訳語メモ

担当400件は **闇の地(어둠의 땅)の秘密要員編**で、questdescription_final の
**10002290〜10002331 / 10002350〜10002420** と対応する。ストーリーは5幕。

1. **###8096-8130 秘密指令**: アーロンが影の扉から闇の地へ送り出す →
   カブリアム盆地避難所のリアムへ$item:30000217$を届け、地獄ベルカウと戦って認められる。
2. **###8131-8217 パパ粉($item:20000046$)捜査**: バロタ商団の密流通品パパ粉を、
   ジンコ→カマ→レフェン(化工学者)とたどり、研究所地下の**パパ粉製造室**を突き止めて掃討。
   奴隷ホージーから「ルミナ解放軍」の名を初めて聞く。
3. **###8218-8299 ルミナ解放軍**: 情報通モスカ →太陽エネルギー実験センターでルイと接触 →
   ケント →マル(妹ビアータ捜索) →奴隷の塔とレノンの消息 →リアム・アーロンへ報告。
4. **###8300-8383 ペカディブステーション救出作戦**: マル／マルンへの指令伝達、
   通行止め標識とブアタンオイル調達 →作戦決行 →ビアータ救出 →赤いマントの指揮官の証言。
5. **###8384-8495 単発クエスト群**: スカーンのポイズンケーブ調査／エルメンと時間のレッドラペンタ
   (テス・ホブ博士)／ジェレミーと桜の森のボロボロ族(ゴーホ・バオバ・ヨミ姫)／
   レイとアルマノの四皇の宝箱／リアムとフィア・ド・カルロ／リナとスダスのクッキー。
