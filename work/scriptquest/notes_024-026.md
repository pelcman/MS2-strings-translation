# バッチ024-026 (###2296-2595) 訳語メモ

新規に「決めた」ものは少なく、大半は既存 jp データ内の既訳を採用した。根拠を併記する。

## 話者名(値には出ないが口調決定の根拠)

- 메이슨 → メイソン(npcname 11004316 ほか)。ルミナイツの高位神官騎士。丁寧語(です・ます)、一人称「私」、「ご苦労さまでした」「フッ」。
- 블리체 → ブリーチェ(npcname 11004312 ほか)。スカイフォートレス艦長。常体・軍人口調、PC を「貴官」、「〜するように」「ご苦労だった」。
- 샤텐 → シャテン(npcname 11004314)。諜報担当、砕けた女性口調。
- 네이린 → ネイリン(npcname 11004315、glossary.tsv にもあり)。グリーンフッド副官、明るい丁寧語。
- 나빌라 → ナヴィラ(npcname 11001396)。「ナビラ」ではない。
- 거스트 → ガスト(npcname 11001443)。医者、丁寧語。
- 치아브 → チアブ(npcname 11001388)。村の年配女性。一人称「あたし」、「〜だよ」「〜ねぇ」「〜しておくれ」の下町のおばさん口調(KO の 〜라우/〜이우 方言相当)。
- 야디 → ヤディ(npcname 11001391、男・兄)、하란 → ハラン(npcname 11001392、女・妹)。
- 아카모로 → アカモロ(npcname 11001397)。
- 분홍 꿈트리 → ピンクニョロリン(npcname 11004556)。※モンスターの 꿈트리 は「グムツリー」(25021401 등)と表記が異なるので注意。
