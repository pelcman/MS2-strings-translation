# scriptquest バッチ039-041 (###3796-4095) 訳語メモ

対象は Kritias_Epic03 の終盤(クラウディア×ジェシカ)と Fame_Geo01(ゲオルク評判クエスト)。
Fame_Geo01 は **jp/questdescription_final.json に公式既訳が揃っている**ため、
用語・言い回しはそちらに全面的に準拠した(下記「既訳準拠」)。

## 新規に決めた訳語(既存訳が見つからなかったもの)

- **모랑족장 칸투랑の語尾「〜다모 / 〜라모 / 〜냐모」→ 「〜モ」**
  (根拠: 既存訳なし。種族名 모랑=モラン に合わせたカタカナ語尾。
   先行バッチの 초로리「〜다초롱」→「〜チョロ」の処理に倣った。
   例: 고맙다모 → ありがとうだモ / 도와줄 수 있겠냐모? → 手を貸してくれるかモ？)
- **모랑모랑 → モランモラン**(モラン族の自称。KO の畳語をそのまま音写)
- **검은 자들 → 黒き者たち**(カントゥランが闇の軍団を指して言う呼称。新規)
- **게오르크 오퍼레이션 HUD → ゲオルクオペレーションHUD**(既存訳なし。カタカナ+HUD は半角)
- **루미윈드 비행선 → ルミウィンド飛行船**(루미윈드 → ルミウィンドは npcfunctionname 11004520 の既訳)
- **임무달성률 → 任務達成率** / **파상공세 → 波状攻勢**(いずれも既存訳なし・漢字語をそのまま)
- **기계 장난감 → 機械の玩具**(ベラがトゥルカ(투르카)を指して言う蔑称。新規)
- **로봇 벌레 → ロボットの虫**(テッサがセクトを指して言う俗称。新規)

## 口調

- 클라디아(クラウディア): 一人称「私」、相手は「お前」。「〜것이야/〜거야」は強気の常体
  (吹き飛ばす／ただでは済まさない／壊してやる)。
- 제시카(ジェシカ): AI らしい冷たい丁寧語(です・ます)。PC を「あなた」。
- 검은 마법사(暗黒の魔法使い): 荘重な常体、自称「我」。벨라(ベラ) は主に対する敬語(です・ます)。
- 홀슈타트(ハルシュタット): 荒い常体(〜か／許さん)。콘대르(コンドール): 既訳どおり砕けた常体。
- 마를레네(マルレーネ): 既訳どおり丁寧語(です・ます)、一人称「私」、PC 呼びは $MyPCName$。
  「수고 많았어요」→お疲れさまでした /「고생 많았어요」→ご苦労さまでしたで訳し分けた。
- 블리체(ブリーチェ): 既訳どおり常体・軍人口調(〜するように／〜だ)、PC は「$MyPCName$隊員」「貴官」。
- 에레브(エレヴ): 丁寧語。테사(テッサ): 難民リーダーの荒い常体(〜だ／〜てくれ)、PC は「異邦人」。

## 訳出上のメモ(原文の不整合)

- ###3892・###3895 は KO 原文が「게오르크(ゲオルク)」となっているが、文脈上は「케르베스(ケルベス)」の
  はず(直後の ###3893 でマルレーネが「케르베스 지휘관들」と言い直している)。原文のバグと判断し、
  タグ・語を改変せずそのまま「ゲオルク」と直訳した。
- ###3881 は KO が「'신비의 힘'」(他は「'신비한 힘'」)と表記ゆれしているが、
  訳語は既訳に合わせて「神秘的な力」で統一した。
- ###4086 は話者欄が「테사」だが内容は PC の提案文((…제안한다.))。PC 行として訳出した。
- ###3928 は話者欄が「PC」だが内容は指示文(…제압하세요.)。原文どおり指示文として訳出した。
