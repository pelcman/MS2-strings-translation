# scriptquest バッチ036-038 (###3496-3795) 訳語メモ

クリティアス Epic02/Epic03 と Fame_Geo01(ゲオルク評判クエスト)の一連。
大半は既存 jp データ(npcname / questdescription_final / achievename)の既訳を採用した。根拠を併記する。

## 話者名(値には出ないが口調決定の根拠)

- 시만 → **シマン**(jp/npcname.json 11004386・11004583・11004615)。ゲオルク副官。丁寧語(です・ます)、
  マルレーネを「$npcName:11004582$様」と呼ぶ忠臣キャラ。
- 콘대르 → **コンドール**(jp/npcname.json 11003534・11004578・11004596。「コンデル」ではない)。
  トライア近衛部長。既訳(scriptquest 130235021023703 ほか)に合わせ豪快な常体、一人称「俺」。
- 요랑 → **ヨラン**(jp/npcname.json 11004576、dict/proper-nouns.json "Yorang")。情報屋のモラン族。
  語尾「〜다모」は **「〜モ」**(초로리の「초롱」→「チョロ」の前例に準拠)。PC は「お客さん」呼び。
- 테사 → **テッサ**(jp/npcname.json 11004574。「テサ」ではない)。難民避難所ガランのリーダー。
  ぶっきらぼうな常体(〜だ／〜てくれ／〜だな)、PC を「이방인」→**異邦人**と呼ぶ。
- 모랑족장 칸투랑 → **モラン族長カントゥラン**(jp/npcname.json 11004620)。語尾は요랑と同じ「〜モ」。
- 안내로봇 → **案内ロボット**(jp/npcname.json 11004585)。丁寧語。
- 마를레네 → マルレーネ(11004582/11004614)。ゲオルクの首長。丁寧語、一人称「私」。
  ただしクラウディアに対してのみ砕けた常体(###3790)。
- 블리체 → ブリーチェ(11004577)。自軍・PC には常体の軍人口調(既訳 stringtrigger 02020023「私を艦長と
  思わないこと」に準拠、一人称「私」)、**ゲオルク側(マルレーネ・シマン)には丁寧語**(KO も 습니다 体)。
- 홀슈타트 → ハルシュタット(11004584)。一人称**「俺」**(既訳 scriptquest 802180211012731 ほか)、
  PC を「お前／貴様／青二才」と呼ぶ尊大な常体。
- 클라디아 → クラウディア(11004385)。女性の砕けた常体(〜わ／〜の／〜よ)。既訳 scriptquest
  123155819010724「私はなんとなく…気がするの。」に準拠。
- 제시카 → ジェシカ(11004575)。人工知能体。慇懃で皮肉っぽい丁寧語。
- 투르카 → トゥルカ(11004430)。一人称「私」+ 尊大な常体。
- 에반→エヴァン / 닉→ニック / 솔베이→ソルベイ / 모니카→モニカ / 랜지→ランジ / 마르→マル
  (すべて jp/npcname.json Season1)。해방군 지령서 → **解放軍の指令書**(npcname 11000909)。
  指令書の文体は事務的な「〜する。」体。

## 訳出上のメモ

- ###3559 は話者が PC だが内容はハルシュタットの拒絶(questdescription 10003230 の
  「彼は必要ないと意地を張った」と一致)。主語を明示せず「(すでに完璧に把握しているので必要ないと言う。)」とした。
- ###3703 は話者ラベルが마를레네だが内容は PC の選択肢。地の文として訳した。
- ###3716 の KO は「준비되었나요?, $MyPCName$.」と「?」の後に読点が入る原文のゆらぎ。
  日本語として不自然なため読点は落とし「さあ、準備はできましたか？$MyPCName$。」とした。
- 原文の行末スペース(###3507/3521/3581/3621/3644/3663/3675/3710)はすべて訳文でも維持している。
