## 公式訳が割れていた箇所とその裁定

- **캐시마트 → キャシーマート**。questdesc 40001310 は「**キャッシュマート**」だが、
  itemname 30000327「キャシーマートタトゥーシール」と mapname 02000209「キャシーマート本店」・
  02000210「キャシーマートカニングシティ店」が命名系。命名系最優先で採用(###9883)。
- **서먼 → サーマン**。questdesc 40001310 の name は「インターン社員**サモン**」だが
  npcname 11001010 が「**サーマン**」。命名系最優先(値には現れない話者名のみ)。
- **따르릉 → チリリン**。questdesc 40001240 は擬音を「**リンリン**」と訳しているが、
  itemname 30000307「**チリリン**ゼンマイ」・npcname 21000280「**チリリン**ラビット」が命名系。
  プレイヤーが見る NPC 名・アイテム名と揃えるため **チリリン** を採用(###9780-9800 ほか)。
- **요정수 → 妖精水**(glossary/命名系と食い違う裁定)。itemname 30000310 は
  「**妖精樹**を入れた緑色の水筒」だが、同一クエストの questdesc 40001251「$npc:11000979$に
  **妖精水**を飲ませてみよう」・40001252「**妖精水**を飲んで落ち着きを取り戻した」が公式。
  文脈は「水筒に汲んで飲む液体」であり itemname 側の「樹」は誤読と判断、
  **単独語の 요정수 は 妖精水** とした(###9828-9830)。※itemname 本体は未変更。
- **추모 공원 → 追悼公園**。itemname 30000373 は「追悼**公演**設立の嘆願書」(誤変換)だが、
  questdesc 40001500 が「追悼**公園**の設立」。本文中の地の語は **追悼公園** とした(###10066)。
  ※$item:30000373$ タグ内の表記は変更していない。
- **하수구 → 下水溝**。questdesc 40001170 は desc「下水**道**」/ manual「下水**溝**」と割れている。
  プレイヤーが目的地表示で見る manual 側に合わせ **下水溝** で統一(###9732-9735)。
