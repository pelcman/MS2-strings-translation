## 新規に決めた訳

- **요랑(モラン族)の語尾 `〜다모/〜라모/〜냐모` → 片仮名の「〜モ」**
  (例: 반갑다모! → よろしくだモ！ / 가져와라모 → 持ってくるモ / 돈 많냐모? → 金を持っているかモ？)
  既存 jp データに前例なし。モラン族の口癖として一貫させる。一人称は「オレ」、自称の `이 요랑님` は「このヨラン様」
- **위상변환 연결체 → 位相変換連結体**(마드라칸 中枢の攻略目標。EN "phase control network"。既訳なし・直訳採用)
- **뿌지직 똥 → ブリブリうんち / 와그작 아몬드 → ボリボリアーモンド**
  (マヨールの「うんち」クエスト。KO はオノマトペ + 名詞。EN は "crunchy chocolate" だが KO 準拠でアーモンド)
- 올케(弟の妻) → **お嫁さん**(ジュマの台詞。「義妹」は硬いので口語表現を採用)
- 원예 소품 → 園芸小物、미확인 에너지원 → 未確認エネルギー源、추천장 → 推薦状(いずれも一般語・辞書登録は任意)
