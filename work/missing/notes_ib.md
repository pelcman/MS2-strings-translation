# itemname 欠落補完 ワーカーI-B (現行 itemname.tsv 1〜800行) 訳語メモ

コーパス・既存 jp データに既訳が無く、今回新たに確定した訳語のみ記載。
I-A (notes_ia.md) の確定訳はすべて踏襲した(ブラックエンペラー / クリスタルシャインド /
古びた闘技場の〜 / 誠実な冒険者の〜 / やんちゃな / ちび / いたずら / 元気いっぱい /
フレッシュな / ふかふか / 綿玉 / チクタク / お出かけ / シマリス / 鉱石の など)。

## 有効だった手法(次のワーカーへの申し送り)

1. **コーパス(dict/corpus/itemname-pairs.tsv)より `json_weblate/{jp,ko,en}/itemname.json`
   から直接作った KO→JA 対訳表のほうが広い**(28,078 組 vs 27,850 行)。
   `깨어난 더키볼〜→目覚めたダッキーボール〜` などコーパスに無い既訳が拾える。
2. **EN 名の完全一致検索が非常に効く。** 同一アイテムが `-Event-` サフィックス付きの
   中国版キーとして jp に翻訳済みで存在することが多く、EN 名一致で 80 件を公式訳のまま補完できた。
3. **他データファイルとの相互参照**:
   - `칭호 : X` → `titlename.json` の X の JP 訳に `称号：` を付ける
     (既訳 86 件中 85 件がこの規則。今回 21 件をこれで確定)
   - `액션 수강증 : X` → `kordynamicaction.json` の `reserved` フィールド(JP)に
     公式の日本語キーワードが入っている(例 `말랑 블랙빈` → `もちもちブラックビーン`、
     `쪼아춤` → `つつき踊り`、`파란색큰깃발흔들기` → `青い大旗振り`)。約 40 件をこれで確定。
   - NPC 名は `npcname.json`(例 `블루 루크` → `ブルールーク`)。

## 判断に迷った点

1. **통통 블랙빈 の擬態語** — 既訳が部位によって割れている(모자→ぷくぷく、장갑/신발/슈트→ぽっちゃり、
   꼬리→ぷくぷく)。핑크빈シリーズの同一部位に合わせて部位ごとに使い分けた。
2. **발랄한 앨리스** — 顔・ベレー帽などは「元気いっぱいな」だが、앨리スシリーズの既訳は
   すべて「元気いっぱいアリス〜」(な無し)。シリーズ内一貫性を優先し「な」を付けなかった。
3. **칭호 : 3주년을 함께한 / 3주년을 빛낸 아티스트** — 中国版キーの itemname 既訳
   (称号：3周年を共にした / 3周年を飾ってくれたアーティスト)と titlename.json の訳
   (3周年を一緒に過ごした / 3周年を輝かせたアーティスト)が食い違う。
   「itemname の 칭호 = 称号：+ titlename の訳」が 85/86 で成立する規則なので titlename 側を採用し、
   4/5 周年も「称号：N周年を一緒に過ごした」で揃えた。
4. **칭호 : 보라해 → 称号：虹を釣り上げた** — 韓国語(BTS由来の「紫でつながろう」)とは
   意味がずれるが、同一アイテムID(20001308)の JMS2 公式訳がこれなので踏襲した。
5. **스타 마그넷 미끼** — 「エサ(スターマグネット)」は既に 별빛 마그넷 미끼 が使用済みのため、
   EN 名(Rainbow Star Magnet Lure)に合わせて「エサ(レインボースターマグネット)」とした。
6. **깍지콩 까망콩 (롱소드)** — 対になる「완두콩 부농콩→グリンピース・ピンクピース」に倣い
   「サヤインゲン・ブラックピース」とした。
7. **감성캠핑 쓸쓸/편안** — kordynamicaction の JP 公式キーワードが「キャンプ寂しい/キャンプ快適」
   だったため、감성 を落としてそれに合わせた。
8. **벚꽃 상자** — 既存 jp の「초보자의 벚꽃 상자 열쇠」は明らかにデータずれ(称号：文字コレクター)
   のため参照せず、「桜ボックス」「桜ボックスの鍵」で新規に統一した。
