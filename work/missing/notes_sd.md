# notes_sd — scriptquest 欠落分 1〜600行(ワーカーS-D)

対象は主に4イベント群:
不滅の武器イベント(ルビィ/バービー)・3周年デイリー・**次元の扉タイムトラベル(アムホスト)**・
2周年/1周年「あの場所に行きたい」「話題の人物たち」。

## 作業方法(重要)

jp/scriptquest.json には**同一本文の既訳が別キーで存在するもの**が大量にあった。
ko/jp を突き合わせて KO→JA 索引(27,052件)を作り、
- 完全一致 167 行 → 既訳をそのまま流用
- タグID(`$item:…$`/`$npc:…$`)だけが違う近似一致 27 行 → タグを位置対応で差し替えて流用
- 残り 406 行(重複除去後 211 パターン)→ 手訳
とした。**既訳流用分は公式訳そのままなので表記の正が入っている**(例: `バービー`『あの場所に行きたい』
`紅葉日報`『話題の人物たち』`ゴルドスグループの総帥』`GMチュンベ`)。

## 表記方針(このバッチで統一したこと)
- **！？は全角**(notes_sc の指摘どおり公式原本の多数派に合わせた)。半角は英数字直後のみ→本バッチでは0件
- NPC名タグ+님 → 様、$MyPCName$님 → さん(notes_sb 踏襲)
- 引用符: **本文中の語句は「」**、**アイテムタグの列挙 `'$item:…$', '$item:…$'` は原文どおり `'…'` のまま**
  (公式訳 207142514003923-Event-KR がこの形なので踏襲)
- `$pp` 系タグはすべて削除して日本語の助詞を直接記述
- 韓国語の `. ` 区切り列挙末尾は `。` に、行末の半角スペースは落とした
- 바비 오빠 → バービーお兄さん(公式訳 2130044140024xx 系に準拠。「お兄ちゃん」ではない)
