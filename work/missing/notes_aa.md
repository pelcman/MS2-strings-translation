# ワーカーA-A 作業メモ (achievedescription / skillname)

## 参照した既存訳の出所

- `achievedescription`: jp/ko の同キー対訳から「タグ・数値を抽象化した文型TM」を作り、
  文型一致分(117行)を自動流用。残りは手訳。
- `skillname`: **同じ数値ID・別サフィックス**のエントリが `json_weblate/jp/skillname.json` に
  日本語で存在する(例 `10100171-JobChange_01-` / `11000011-Striker-` / `11100011-SoulBinder-`)。
  これを最優先の正として 160行を確定、さらに同一KO名・同一数値IDへ波及させた。
  絵文字系(902xxxxx)は `jp/kordynamicaction.json` と itemname「アクション受講証：〜」の公式訳を使用。

## 判断に迷った点・申し送り

1. **既存 jp データの誤りを2件、踏襲せず修正した**
   - `92000118--`(既存)は KO「10회 먹이 주기」に対し JP が「100回エサを与える」。
     今回の `92000148-Event-{KR,CN}` は KO が **15회** なので「15回エサを与える」とした。
     (既存 92000118 側の 100回 は誤りの可能性が高い)
   - `23500010-Season1-`(既存)は KO「목걸이(=ネックレス) 제작 전문 메이드」に対し JP が
     「イヤリング製作専門のメイド」。対象アイテム 11900054 も achievename 23500010 も
     **ネックレス**なので、今回の `23500010-Season1-KR` は「ネックレス製作専門のメイド」とした。

2. **desc / complete は原則同一文にした。**
   既存 jp/achievedescription.json は desc==complete が 752件 / 異なるものが 164件で、
   KO 側が「〜하기」/「지금까지 〜!」の違いしかない場合は日本語を同一にするのが JMS2 の慣行。
   KO の内容自体が異なるもの(例 92000092 の 1000日メッセージ)は個別に訳し分けた。

3. **skillname は「同じ数値ID・別サフィックスの日本語名」を最優先**した。
   そのため KO 名と字面が一致しないものがある(いずれも JMS2 公式名)。例:
   - `10100261` 신성한 연격(Holy Combo) → **ディヴァインカット**
   - `10100281` 실드 오라(Shield Aura) → **イージスバラージ**
   - `10200181` 달 쳐내기(Moon Strike) → **パリーザムーン**
   - `10300211` 찌릿 치릿(Zap Zap) → **パーフェクトストーム**
   - `10300261` 빅폴(Big Fall) → **氷の精霊**
   - `10500293/10500296` 사거리 확보 / 이글 스쿼드 효과 → **キャプテンイーグル**
   - `10600251` 아모 제너레이터 → **ミサイルスーパーチャージャー**
   - `11000315/11000319` 혈도 개방EX N단계 디버프 → **ねじれN段階**
   - `10200234` 강화 돌개 바람 → **つむじ風**(JobChange 後は 10200233 も同名)
   これらを KO 直訳に戻したい場合は要相談。

4. DungeonOS01(ブルールーク)/DungeonOS04(オペラ)の内部スキル名は開発用の記述的名称のため、
   `Crawl` `light` `effect` `loop` `push/attack` 等の英字はそのまま残した。
