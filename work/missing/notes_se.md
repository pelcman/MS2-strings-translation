## 表記方針(このバッチで統一したこと)
- **！？は全角に統一**(notes_sd 踏襲)。出力 598 行中 全角 997 / 半角 0
- NPC名タグ+님 → 様、$MyPCName$님 → さん、씨 → さん(notes_sb/sc/sd 踏襲)
- 引用符: 本文中の語句は「」。ただし**アイテムタグの列挙 `'$item:…$', '$item:…$'` は原文どおり**
  (公式訳 207142514003922〜3924 / 126211317003128 に完全準拠)
- ボス名の羅列(`$npcName:23000013…$, …`)は **`, ` 区切りのまま、末尾のみ `.`→`。`**
  (公式訳 207142514003923 に準拠)
- `$pp` 系タグはすべて削除し日本語の助詞を直接記述。行末の半角スペースは落とした
- 口調: ルビィ/バービー系イベントNPCは明るい丁寧語。カササギ(003695〜)は年長者口調(わし/君/〜かね)、
  カルボナ(003724〜)は親しいタメ口(僕/君)で訳し分けた
- チルダは公式原本に合わせ **半角 `~`**(`ですよ~` など)

## ★重要: 元ファイル `work/missing/scriptquest.tsv` の不整合(要共有)
- **34〜35行目が物理行として壊れている**。キー `701171817004548-Event-CN` の KO/EN に
  生の改行(おそらく元データの `\r`)が残っており、1レコードが3物理行にまたがる。
  → **指示された自己検証スクリプトはこの行で IndexError で落ちる**(`r[1]` が存在しないため)。
  本ワーカーはキー行判定 `^[0-9]+-[A-Za-z]*-[A-Za-z]*\t` で論理行を再構成して検証した。
- そのため **担当範囲「物理行1〜600」= 論理レコード598件**。出力も598行(⏎1個で正しく連結済み)。
- ファイル全体では同種の壊れ行が **184行**(1946〜2011, 2034〜2046 ほか)ある。
  後続ワーカー(1946行目以降担当)は特に影響が大きいので、
  分割前に `\r` を ⏎ に正規化するか、キー行判定で論理行を組み直すことを推奨。
