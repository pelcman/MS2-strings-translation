# itemname 欠落補完 ワーカーI-D (現行 itemname.tsv 1〜700行) 訳語メモ

I-A / I-B / I-C の確定訳はすべて踏襲。

## ★最重要の発見: 中国版(CN)キーは「同一アイテムIDの韓国版行」から公式訳が取れる

担当範囲 700 行のうち約 580 行が `--CN` / `-Develop-` の**中国語原文**行だった。
これらは KR の同一アイテムを中国版で改名しただけのものが多く、次の 2 経路で公式訳が特定できる。

1. **同一数値ID・別サフィックスの jp 行**
   例: `11250077--CN 东方仙人耳环（男）` ↔ `11250077-- 천계의 선인 귀고리 (남)` → 天界の仙人イヤリング(男)
   `20001302-Event-CN` ↔ `20001302-Event-JP` → パチパチハートキャンディ
   `20300661--CN 会员3天体验券` ↔ `20300661--` → プレミアムクラブ利用券(3日)
   **注意**: ID 再利用が実在する。`11320435-Develop-(鲫鱼烧帽子)` の同 ID jp 行は
   `-ItemKR- (ネットカフェ) やんちゃなちび悪魔の角` で完全に別物だった。
   採用前に必ず「部位・テーマが一致するか」を確認すること。
2. **jp/ko 全ファイルから作る CN→JA 対訳表(約 7,800 組)**
   ko 側が中国語で jp 側が翻訳済みのエントリが多数存在する(itemname だけでなく
   koritemdescription / questdescription_final などにも)。
   例: `东方天使鞋（男）→ オリエンタルエンジェルシューズ(男)`、`红色蘑菇币→レッドメロット`、
   `金币包裹：X金币→メル袋：Xメル`、`水晶碎片→クリスタルの破片`、`玛瑙→オニキス`
3. 部分一致が効かないときは **KR シリーズ名を推定 → ko 側前方一致でシリーズ全部位を一括取得**
   (`천계의 선인` `키튼 메이드` `디그니티 아머` など) が最も速い。

## その他の定型・確定訳

- 배지 系: `메타 배지 : X의 표식` → `メタバッジ：Xの証`(표식→証 は「용맹의 표식→勇猛の証」準拠)。
  말풍선=吹き出しバッジ / 이름표=ネームタグバッジ / 대미지 폰트=ダメージフォントバッジ /
  수영 튜브=浮き輪バッジ / 낚시=釣りバッジ。`낚시 배지`の `말랑` は **るんるん**(既訳準拠)。
- `룩 패키지` → ルックパッケージ、`의상 패키지` → 衣装パッケージ、`(1회 거래 가능) 교환 쿠폰` → `(1回取引可能)交換クーポン`
- 궁중 예복→王宮礼服 / 보름달 한복→満月韓服 / 색동 한복→レインボーオリエンタルコスチューム
  / 모던 한복→モダン韓服(すべて categoryname の既訳)
- 점검 보상→メンテナンス補償、휴양지→リゾート、우리의 친구 X→みんなの友達X、바키→バッキー
- CN `（样本）` = KR `(본)` = **(本)**(楽器・釣り竿のサンプル表記)。
- ポーション類の公式訳: 不死の守護 / 鋼鉄の保護 / 非凡な集中 / 凝縮された強化 / 燦然とした輝き /
  純潔の結束 / 凝縮された乱暴 / 風の迅速。エリクサー系は バイタル / エネルギー / リカバリー。
  数量は CN の `（30个）` に合わせ `(30個)`。
- `X级宝石箱子`(ItemSocketSystem) → `X段階ジェムストーン宝石箱`(20000679 既訳準拠)

## 判断に迷った点

1. **`-Develop-` と `--` の ID 衝突** — 11320425/26(交叉蝴蝶结帽子 vs 알록달록 조개 머리 핀)と
   11320433/34(鸭舌帽 vs 출렁 파도 머리핀)、11320435-438(PC방アイテム)は明らかに別アイテムなので
   ID 一致を採用せず CN から訳した。11220423/11320423(冬季制服 vs 빛나는 눈꽃)は
   耳飾り・帽子の 2 部位で対応が揃うため同一アイテムと判断し公式訳を採用。
2. **12200495-- の jp データが壊れている**(천계의 선녀 드레스 → ハッピークリスマスホームウェア全身服(男))。
   参照せず「天界の天女ドレス(女)」とした。
3. **12200601 洛可可带饰裙（女）** — 男性版 12200600 が 중세 귀족 슈트 と対になるため
   シリーズ整合を優先して「中世リボンドレス(女)」(KR 중세 리본 드레스の公式訳)を採用。
4. **20001782 熊熊燃烧爱心糖** — 20001302 と同じ「熊熊燃烧」表記で、JP 公式が
   パチパチハートキャンディ のため同名を割り当てた。別アイテムの可能性は残る。
5. **20001321 称号：烈日阳光**(EN Blazing Sunlight) — 既訳「称号：サンシャイン」は
   CN 「称号：阳光」に対応する別称号なので、区別のため「称号：灼熱の太陽」とした。
6. **11601313/14 流氓兔头带** — グローブ枠なのに CN 名は「头带(ヘアバンド)」。
   CN 原文どおり「いたずらウサギのヘアバンド」とした。**要再検討**。
7. **11820433 基本款校园背包(男)** — 同 ID の jp は「ミステリークラブカバン」だが
   (女)側 11820434 に KR 行が無く男女で訳が割れるため、シリーズ一貫性を優先して CN から訳した。

## 作業ノート
