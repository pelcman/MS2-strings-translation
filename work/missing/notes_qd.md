## ★最重要の申し送り: JP専用キーは「翻訳不要」

`-Event-JP` サフィックスのキーは **ko ファイル側の値が最初から日本語**(JMS2 公式テキスト)。
訳出は一切不要で、KO 列をそのままコピーすればよい。今回 700 行中 **389 行(55%)がこれ**だった。
判定は単純に「KO 列にハングルが 1 文字も無い」でよい(700 行中、非ハングル行 = Event-JP 行が完全一致)。

    python -c "...  if not re.search('[가-힣]', ko): ja = ko"

**残りの担当者は、まずこの判定で機械的に埋めてから手訳に入ること。** 実質の手訳は 311 行だった。

## 判断が分かれる点(次ワーカー/レビュー向け)

1. **`모험[일반/어려움] ボーナスボックス` の `]` 後のスペース**
   jp 全体で「スペースあり」46 件 / 「なし」9 件。itemname 20301412 と 89080002-Event-JP(JP 公式)が
   **スペースあり**なので**スペースありに統一**した。
   ただし既存の 89050022 / 89050052 / 89050082 は**スペースなし**で入っている(前ワーカーの表記)。
   統一するならそちらの修正が必要。
2. **89050076 / 89050106 の name が KO と数値不一致のまま jp に存在する**
   jp: `30分間演奏する` / KO: `10분`・`1분`。同様に 89050082(KO 5개→JA 10個)、
   89050083(KO 5개→JA 10個)、89050084(KO 1회→JA 3回)、89050085(KO 3회→JA 10回)、
   89050087(KO 5회→JA 10回)、89050089(KO 3마리→JA 5匹)、89050067(KO 300점→JA 700点)なども同様。
   **数字を `#` に正規化したテンプレート照合で埋めた際に、元テンプレートの数字がそのまま残ったもの**と思われる。
   今回担当した manual / complete は **KO の数値に忠実**に訳した(10分間演奏する / 1分間演奏する)ため、
   同一クエスト内で name と manual の数値が食い違う。**name 側の一括修正を推奨**。
3. **`(주간 퀘스트 포함)` → `(週間クエスト含む)`**
   `[주간]` タグ単体は `[ウィークリー]` だが、既存 89050020/89050050 が `(週間クエスト含む)` なので
   括弧書きはそちらに合わせた。
4. **クエスト名の引用符**
   既存 89050009 は `[デイリー] トリック・オア・トリートを3回完了`(括弧なし)だが、
   89060023〜89060030 は対象クエスト名に `！` が含まれ地の文と切れ目が分からなくなるため
   `[デイリー] 「見習いルドルフとクリスマスツリーを飾ろう！」を3回完了` のように **「」で括った**。
5. **`크리스마스 댄스댄스스탑`(公式訳 `クリスマス・ダンス・ストップ！`)を文中に埋め込む**と
   `クリスマス・ダンス・ストップ！で/こんにちはを10回する` となり `！` が文中に来る。
   JP 公式 30000382 desc も `$map:61000022$に参加し` と地の文に埋め込んでいるため、そのまま採用した。
6. **`모험레벨 N레벨업하기`** は JP 公式 89080001-Event-JP が `冒険レベル10段階レベルアップ` なので
   `冒険レベルをN段階レベルアップする` を採用(「Nレベルアップ」ではない)。
