## 作業方法(次のワーカーへの申し送り)

1. Q-A のパターン索引を踏襲し、ko/jp 同キー同フィールドを「タグをスロット化」して突合 → **94 行**を公式訳で復元。
2. **さらに強力だったのが `scriptquest` からの逆引き**。この 700 行のイベント群は
   `scriptquest` 側に**同じイベントの NPC セリフが公式訳付きで丸ごと残っている**。
   - 「그곳에 가고 싶다」イベント → `scriptquest 213004414002395〜002449`(および `621160714000763` 系)
   - 「넘버원 페스티벌 / 1주년」特集 → `scriptquest 213004414002476〜002641`(および `621205014000816` 系)
   ここから各地の紹介文・人物紹介文の**公式訳をそのまま流用**できた(下表)。
   **同じ手が他のイベントクエストにも効くはずなので、まず scriptquest を探すこと。**
3. 1〜700 行のうち **270 行は KO 原文が完全重複**(판타스틱 미션 80000135〜80000179 など)。
   `(フィールド名, KO原文)` をキーにした自己流用で機械的に埋めた。訳出が必要な実質行数は約 340。

### 定型句(パターン索引で復元した公式訳)
- `$map:A$이나 $map:B$에서 $npc:C$$pp:와,과$ 대화하기` → **`$map:A$または$map:B$で$npc:C$と会話する`**
  (「이나/또는」= **または**。70200062「$map:02000058$ 또는 다른 곳에서」→「$map:02000058$または別の場所で」に準拠)
- `$item:X$ 이용하기` → `$item:X$を体験する` / `$item:X$ 작동하기` → `$item:X$を作動させる`
- `$item:X$ 사용하기` → `$item:X$を使用する` / `$item:X$ 획득하기` → `$item:X$を獲得する`
- `$map:X$ 방문하기` → `$map:X$を訪問する` / `망원경 보기` → `望遠鏡を見る`
- ボス列挙の `'A', 'B',` → `「A」、「B」、`(カンマは **、**、引用符は **「」**)
- `신나게 달려보자!` → `思いっきり走ってみよう！` / `파란 하늘을 향해 힘차게 점프를 해보자!` → `青い空に向かって力強くジャンプしてみよう！`
- `탈것에 몸을 싣고…구경해보자!` → `乗り物に身を乗せて…見物してみよう！`
- `어푸어푸 헤엄을 쳐보자!` → `バシャバシャ泳いでみよう！`

## 判断が分かれる点(次ワーカー/レビュー向け)

1. **文字集めクエスト 80000106〜80000109**
   対象アイテムの**公式 JA 名が壊れている**(itemname 30000589〜30000596: 신=神 / 나=し / 는=い /
   메=メ / 이=イ / 플=プル / 축=祝 / 제=**第**)。つまり JA では「神しい」「メイプル」「祝第」となる。
   プレイヤーが実際に集めるアイテム名と一致させるため、**クエスト名も公式アイテム名を連結した表記**
   (「神しい」「メイプル」「祝第」)を採用した。意味重視で「ワクワク」等に意訳するとアイテムと紐づかないため。
   → もし itemname 側を修正する方針になるなら、ここも連動修正が必要。
2. **80000232 desc の KO は「폭주열차 블랙노프 1호」を 2 回繰り返す原文ミス**
   (2 行目の $npc:24002109$ は本来 2 号のボス)。他クエスト(80000181/80000203/80000204/80000236)の
   폭주열차/난폭열차 の区別および stringfieldenterance の公式ダンジョン名に合わせ、
   **1号 / 2号 と訳し分けた**(KO 直訳ではない)。
3. **난폭열차 블랙노프호** は KO 側の表記ゆれ。公式ダンジョン名が「暴走列車ブラックノフ2号」なので
   全て **暴走列車ブラックノフ2号** に統一した。
4. 원문の行末スペース(`이벤트! ⏎` など)は公式 JA 訳も保持している例が多いため、**そのまま維持**した。
