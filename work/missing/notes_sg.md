## 表記方針(このバッチで統一したこと)

- **！？は全角に統一**(半角 0 件。英数字直後もなし)
- NPC名タグ+님 → 様、$MyPCName$님 → さん、아저씨 → おじさん、아가씨 → お嬢様
- `$pp`/`$pp2` タグはすべて削除し、日本語の助詞を直接記述(残存 0)
- **ボス18体の羅列**は 2 系統の公式訳が存在するため、**同一クエスト系列の公式訳に合わせて訳し分けた**:
  - メイプルフェスティバル系(1005215514001262 等)= `, ` 区切り + 末尾 `。` + 「これらのボスから文字…を探してみてください。」
  - 떡국/바람개비系(1211182214004476 等)= `、` 区切り + 「…などを討伐すれば手に入れられます。」
  - ルビィのファンタスティック系(1103175514001387 等)= `, ` 区切り + font タグ内 + 「…がいるんです！」
- 引用符: 本文中の語句・手紙の引用は「」。**アイテムタグの列挙は原文どおり `'$item:…$'`**。
  ただし 1211182214004476〜004482(떡국)は公式の바람개비版に合わせ **「$item:…$」** とした
- チルダは半角 `~`。ただし公式訳を流用した行のみ全角 `～`(公式原文どおり)
- モンスター種別の訳語は**テンプレートごとに公式訳が異なるため公式に従った**:
  - 「몬스터 도감 사업」系 → 인간형=**人間型**、사물형=物体型、벌레형=虫型、신수형=神獣型、언데드형=アンデッド型
  - 「이곳에 있는 동안 몬스터 도감」系 → 인간형=**人型**(★同じ「인간형」でも訳が違う。公式どおり)
- 口調の訳し分け:
  - ルビィ/バービー = 明るい丁寧語 / MC ケイ(司会者ケイ)= 芝居がかった丁寧語「〜なんです」
  - 근위대장 프레이 = 「お前／〜だろうな」(公式 1021190117004423 準拠)、部下 = 丁寧語
  - 쁘띠 자쿰 = 「僕／〜クム」 / 페르아(ItemMerge) = くだけたタメ口「〜だよ／〜なんだ」
  - 이브(반신/권속と呼ぶ存在)= 荘重な丁寧語 / 라네모네 = 快活なタメ口「〜だぞ／〜だな」
  - 에레브(女王) = 丁寧語「〜いらっしゃいました」
