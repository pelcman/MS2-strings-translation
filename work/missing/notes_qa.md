# notes_qa — questdescription_final 欠落補完 1〜700行(ワーカーQ-A)

対象は 3 群:
1. **80010xxx 系イベントクエスト**(ダッキーボール/星風船/なぞなぞ「〜の挨拶」/ダークストリーム征服/
   ジャクム風船・ジャクム建設/サンタパパのツリー/メイソン/バレンタイン/春の文字集め)
2. **89010xxx・89020xxx・89030xxx 系「今日のミッション」型デイリー**(約 490 行。name/manual/complete が
   ほぼ同文の反復)
3. **80000xxx 系イベント**(幸運のボックス/五色袋/春のオーラ/子犬キャンペーン/大激戦)

## 作業方法(次のワーカーへの申し送り)

1. ko/jp を **タグをスロット化した「パターン索引」**で突合(`$pp:…$` を除去し `$xxx:ID$` を位置対応の
   プレースホルダに置換)→ **118 行**を公式訳のテンプレートに自分のタグを差し込んで復元。
   `$map:X$에서 $npc:Y$$pp:와,과$ 대화하기` → `$map:X$で$npc:Y$と会話する` など。
2. **タグ種別は KO をそのまま踏襲**して問題ない。jp/ko の同キー同フィールドで
   `$npc:`↔`$npc:` 7,857件 / `$npcName:`↔`$npcName:` 6,464件に対し不一致はわずか 12 件。
3. **同一キーに既訳フィールドがある場合はそれを最優先**。89020001/06/11/16/21/26/31 と 89010093 は
   jp に `name` だけ存在し、その値が **KO 原文と内容が食い違う**(例: 89020011 KO「메이플 가이드 퀘스트
   1개 완료」→ jp name「レベル30を達成する」、89020021 KO「50레벨 달성」→ jp name「レベル40を達成する」)。
   同一クエストの manual/complete は jp name に揃えた。**KO 直訳にするとゲーム内で矛盾する**ので注意。
4. **89050xxx-Event-NA 系の既訳は回数を省いた意訳**(KO「낚시로 물고기 200마리 낚기」→ jp「釣りで魚を釣る」、
   KO「$dungeonTitle:25008001$에 도전하여 5라운드 통과하기」→ jp「$dungeonTitle:25008001$」だけ)。
   一方 **89010xxx 系の既訳は回数を保持**(89010043 KO「젬스톤 업그레이드 1회 성공하기」→
   「ジェムストーンのアップグレードに1回成功する」)。**89010/89020/89030 系は回数を保持する方針に統一**した。

  「$map$で一番親切な彼女は誰でしょう？彼を見つけてあいさつをしてきたら…」の言い回しを踏襲)
- 친절한/부지런한/지적인/듬직한/상큼한/성실한 →
  **親切な/勤勉な/知的な/頼もしい/爽やかな/誠実な**(듬직한=頼もしい は itemname 50600166、
  상큼한=爽やかな は koritemdescription 11300196 準拠)
- **폴짝폴짝 → ぴょんぴょん**(skillname 90200093)/ **어푸어푸 → バシャバシャ**(scriptquest 212201214002145)
- **신나게 달려보자 → 思いっきり走ってみよう**(scriptquest 822175917002920)
- **탈것에 몸을 싣고 이곳저곳을 구경 → 乗り物に身を乗せて…あちこちを見物**(scriptquest 822175917002925)
- **자쿰の語尾「〜쿰」→「〜クム」**(scriptquest 1107112617002961「調べてみるクム」)。
  80010035 name「자쿰을 건설하자쿰!」→「ジャクムを建設するクム！」
- 引用符 `'…'` は **「…」** に、`[…]` は半角角括弧のまま(scriptquest/questdescription_final の既訳に準拠)
- ボス列挙のカンマは **、**(questdescription_final 73000013-FieldEventSpawn の既訳に準拠)
