# itemname 欠落補完 ワーカーI-C (現行 itemname.tsv 1〜800行) 訳語メモ

I-A / I-B の確定訳はすべて踏襲(ブラックエンペラー / クリスタルシャインド / 誠実な冒険者の〜 /
勇敢なダッキー消防隊員 / ふかふか綿玉 / スノーフラワー / ブルールーク / 双手・上・下・片手・両手 など)。

## 有効だった手法(次のワーカーへの申し送り)

I-B の手法(itemname 直接対訳表 / EN 完全一致 / 他ファイル相互参照)に加えて、
**「KO 原文を部分文字列として含む他ファイルのエントリ」を探す検索が非常に効いた。**
とくに `nametagsymboldesc` は「<アイテム名> 사용 시 획득」の形で itemname をそのまま含むため、
マーク系ボックスの公式訳がそのまま取れる(今回 5 件を公式訳で確定)。

- `nametagsymboldesc` / `nametagsymboltitle`: マーク(ネームタグ)系アイテムの公式名
- `stringfieldenterance` / `mapname`: ダンジョン名(ランク報酬ボックスの前半部)
- 全 json ファイルを横断した KO→JA 対訳表(約 4.5 万組)＋トークン単位のヒント付与が有効

## 定型パターン(既訳準拠で機械適用)

- `N단계 엑설런트/에픽/레전더리 인챈트 주문서(X)` → `N段階エクセレント〜エンチャント呪文書(X)`
  (표창→手裏剣、블레이드→ブレイド、홀→セプター、라지소드→ラージソード、상하의→上下)
- `X 옵션 (수치) 변경권 (부위)` → `Xオプション(数値)変更券(部位)`。レベル付きは `(LV70/防具)` の形
- `파괴의 젬스톤 (N단계)` → `破壊のジェムストーン(N段階)` / `고급 〜` → `高級破壊の〜`
- `〜 X랭크 보상 상자` → `〜Xランク報酬ボックス`
- `상의 상자 / 하의 상자` → `服ボックス(上) / 服ボックス(下)`(既訳「난폭한 상의 상자→乱暴な服ボックス(上)」)
- `상의,하의 선택 상자` → `服選択ボックス(上下)`、`모자,장갑,신발 선택 상자` → `帽子/グローブ/靴選択ボックス`
  (Level70Item 系は `、` ではなく `/` 区切りが既訳)
- `조각` は装備・ボックス由来なので一律 `〜の欠片`

## 判断に迷った点

1. **추석 → お盆** — 公式の唯一の前例(mapname「# 캐릭터 선택창 - 추석→# キャラクター選択 - お盆」)に従った。
   厳密には中秋節だが、既訳一貫性を優先。「추석 보름달상→お盆の満月賞」「2021 추석 스페셜 캡슐→2021 お盆スペシャルカプセル」。
2. **N월 더키의 꾸미기 캡슐/코인** — 既訳(22001017〜24)は月を落として全部
   「ダッキーのアバターカプセル」に潰されている。今回は 28 件が同名になってしまうため、
   月・年を残して「22年3月ダッキーのアバターカプセル」の形にした(基語 꾸미기→アバターは既訳準拠)。
   여름맞이 は「夏を迎える」とした。
3. **찬란한 미지의 초월 수정(71LV)** — 既訳「미지의 초월 수정(71LV)→未知の超越水晶(70LV)」は
   レベル表記が 70 にずれている(誤りと思われる)。他ファイル(stringfieldenterance)では
   jp も「71レベル」を使っているため、こちらは **(71LV)** を採用した。
   찬란한→燦然とした は「찬란한 광휘 물약→燦然とした輝きポーション」準拠。
4. **글자 아이템 바/깥/은/따/뜻 (30001309-11, 30001318-19)** — イベント
   「바깥은 쌀쌀해 메2는 따뜻해」の文字集めアイテム。既訳分(쌀→米、해→す、메→メ、는→い)は
   規則性が読み取れず流用できないため、日本語文「外は寒い メ2は暖かい」の文字を割り当てた
   (바→外、깥→は、은→寒、따→暖、뜻→か)。**要再検討**。
5. **회차 / 주차** — それぞれ「N回目」「N週目」とした(korflash の既訳「최근 4회차→直近4回目」準拠)。
6. **넥캐상자** — 넥슨캐시の略語。日本語は略さず「逆転！100,000 NEXONポイントボックス(N回目)」。
7. **꾸미기 월척/대박 상자** — 두근두근/월척이오 は既訳の ドキドキ／大物だ！ を使用。
   꾸미기 は アバター に揃えた(「ドキドキ！アバター大物ボックス」)。
8. **수영 튜브 배지 종이배 선택 상자** — 既訳の「수영 튜브 배지 : 종이배→浮き輪バッジ：折り紙の船」を
   踏まえ、原文にコロンが無いので記号を足さず「浮き輪バッジ折り紙の船選択ボックス」とした。
9. **캐릭터 귀속** — 既訳なし。「キャラクター専用」とした。
