## 作業方法

jp/scriptquest.json に**同一イベントの別リージョン版の既訳**が大量にあった。
ko/jp を突き合わせて正規化キー(タグ・fontタグ・空白を除去)で索引を作り、
完全一致 8 行 + 近似一致 43 行 = **51 行を公式訳から流用**(表記の正が入っている)。
特に月ウサギイベントは JP 版(도라야끼=どら焼き)の完訳が存在したので、
文体・語彙をそのまま踏襲して KR 版(송편)/CN 版(월병)に移植した。

## 表記方針(このバッチで統一したこと)
- **！？は全角に統一**。半角は 1 箇所のみ = `( ! )を押して確認`(905173314004189)。
  これはゲーム内のクエストマーカー記号なので原文どおり半角を維持した
- NPC名タグ+님 → 様、$MyPCName$님 → さん、씨/양 → さん、아저씨 → おじさん
- `$pp` / `$pp2` 系タグはすべて削除し、日本語の助詞を直接記述
- 引用符: 本文中の語句は「」。**アイテムタグの列挙 `'$item:…$'` は原文どおり `'…'` のまま**
  (notes_sd/se 踏襲)。ボス名の羅列は `, ` 区切りのまま、末尾のみ `.`→`。`
- チルダは半角 `~`。ただし原文が長音的に伸ばす `~~~` はそのまま維持
- 口調の訳し分け:
  - ルビィ/バービー(イベントガイド)= 明るい丁寧語「〜ですよ／〜しましょうか？」
  - 女王エレヴ・守護司祭ルアーナ = 丁寧語、近衛隊長フレイ/上官 = 「〜せよ／〜するように」
  - ブリーチェ艦長 = 「諸君／〜のだ」、シャテン = 女性的なくだけた口調「〜のよ」
  - 칸타타(11000324)の「맨」= **マン**(既訳 요~ 맨~ → ヨー～マン～ に準拠)
  - 체셔 / 놀랐냥 系のネコ語尾 냥/옹 = **にゃ／にゃん**(既訳準拠)
  - ハロウィンの魔女 = 「わし／お前さん／〜だろう？」
- 「고구마 화로」「절구」等は itemname タグのため訳出せず、地の文のみ日本語化
