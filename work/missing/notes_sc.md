## 表記方針(このバッチで統一したこと)
- notes_sb 踏襲: 짝꿍=相棒 / 술래잡기=鬼ごっこ / 이성 친구=異性の友達 /
  NPC名タグ+님=様、$MyPCName$님=さん、모험가=冒険者(公式原本134件 vs 冒険家11件)
- 여자 친구 / 남자 친구(このイベントでは恋人ではなく「同性・異性の知人」)→ 女性の友達 / 男性の友達
- 명칭・타이틀・칭호 はすべて「称号」
- 引用符 '…' / "…" は「…」に統一。KO のカンマ区切り列挙は「、」に置換
- `$pp` 系タグはすべて削除し、日本語の助詞を直接記述
- KO 行末の半角スペースは訳では落とした。行末の `⏎`(空行)はそのまま維持
