# itemname 欠落補完 ワーカーI-E (最終517件) 訳語メモ

I-A〜I-D の確定訳はすべて踏襲。担当517行は**全行が中国版(CN)の中国語原文**だった。

## ★最重要の発見: `koritemdescription.json` の jp 側に CN キーの公式訳が大量に残っている

I-D の「同一数値ID の jp 行」「CN→JA 対訳表」に加えて、**説明文ファイルの相互参照が決定打**だった。

`json_weblate/jp/koritemdescription.json` には `...-CN` キーそのものに対する
**日本語訳のツールチップ/ガイドが入っている**ため、アイテム名が説明文中に埋め込まれている場合、
そこから公式訳を確定できる。担当517件のうち約80件をこの方法で確定した。

例:
- `20301260--CN 冰水灵箱碎片` の tooltip = 「アイススライムボックスの欠片」
  → 20301257 冰水灵箱 = **アイススライムボックス**(冰雪人=アイスイエティ、冰扎昆=アイスジャクム)
- `20301040--CN 兴儿亲制便当` の tooltip = 「レイの好きな食べ物が入っているお弁当」
  → CN 兴儿 / 张艺兴 = **レイ**(EXOのLay。CN限定コラボ)
- `20301732--CN 老司机箱` の tooltip = 「初心者と一緒にカオスダンジョンをクリアした熟練冒険者に…」
  → 20301515 친절한 기사 상자 と同一 = **親切な騎士ボックス**
  (KR 기사 = 騎士/運転手 の掛詞を CN が「老司机」と訳したもの)
- `20303154-Event-CN 初级大厨箱子碎片` = 「初級パティシエのボックスの欠片」→ 大厨 = **パティシエ**
- `21100007-ChatEmoticon-CN` = 「チャットで使えるウルジャの絵文字」→ CN 金刚熊 = **ウルジャ**

作った補助スクリプト(`work/missing/_ie_*.py`)
- `_ie_build.py` 全ファイルから CN→JA(約8,400組)/KO→JA(約12万組)対訳表を生成し、担当行にヒント付与
- `_ie_desc.py` 指定アイテムIDの**全ファイル横断の説明文**(jp/ko)をダンプ ← 今回の主力
- `_ie_nb.py` 数値ID の前後±3 を jp/ko/en 3言語で並べる(シリーズ名の特定に有効)

## 判断に迷った点(要再検討)

1. **`31001632-45 +10卓越级强化符文 (部位)` を「呪文書」にした** — CN 符文は
   20301558-69(交换箱)では KR 인챈트 **룬**=エンチャント**ルーン**に対応するが、
   31001632 の jp 説明文が 31001658(인챈트 **주문서**)と完全同型
   (「70レベルのエクセレント等級の帽子にのみ使用できる。…+10エンチャントアイテムになる」)
   のため、こちらは **エンチャント呪文書** を採用。「+10 」接頭辞は原文どおり残した。
2. **`20302803 2周年领主纪念箱` の「领主」が全データ中この1件のみ**で対訳が取れず、
   直訳の「2周年領主記念ボックス」とした。同シリーズ(坐骑=乗り物/动作=アクション/
   皮肤=アバター/徽章=バッジ)から見て何かのコンテンツ区分名の可能性が高い。**要再検討**。
3. **同義で衝突する箱名を機械的に差別化した** —
   20301605 夏日斗燃装备箱=サマーバーニング装備ボックス(jp説明で確定)に対し、
   20301735 燃烧夏季装备箱 は同義だが別IDのため「バーニングサマー装備ボックス」とした。
   同様に 20301059 超越时光箱=超越の時間ボックス / 20301663 时间赛跑箱=時間とのランニングボックス
   (両者とも jp 説明文は「時間とのランニング…」で同一)。
4. **文字集めアイテムは簡体字→日本漢字の1対1変換にした** —
   `冒险岛春暖花开`→`冒険島春暖花開`、`夏树苍翠仲夏夜梦暑月蝉鸣`→`夏樹蒼翠仲夏夜夢暑月蝉鳴`、
   `暖冬行迎春季浪漫时`→`暖冬行迎春季浪漫時`、`冒险岛喜迎新春`→`冒険島喜迎新春`。
   I-C の「日本語文に置き換える」方式は取らず、パズルの対応関係を保存する方を優先した。
   なお `夏`/`暑`/`新` は既訳と完全一致した。
5. **`30001352 闪烁的樱花瓣`→「きらめく桜の葉」** — 公式既訳「반짝이는 벚꽃잎→きらめく桜の葉」が
   誤訳(잎=葉ではなく花びら)だが、一貫性を優先してそのまま採用した。
6. **`30001477 雪花硬币`→「雪の花コイン」** — 눈꽃 は原則スノーフラワーだが、
   この項目の jp 説明文が「雪の花ショップ」と書いているため合わせた。
7. **`22301004-24 / 22302002-08` のカプセルパッケージ** — 既訳(22001001-16)は (N차) を落として
   全部同名に潰しているが、21件が同名になるため I-C の方針に倣い「(第N期)」を残した。
8. **`20302799/20302800` は jp 説明文の赤/青が原文と逆転している**(データ側の誤り)。
   itemname 側の色(红=赤、蓝=青)を正とした。
9. **`30001431-433`** は jp に `-Event-JP`(パンプキンジュエル/幽霊魚)と `--`(カボチャの宝石/
   ゴーストフィッシュ)の2系統がある。KR 由来の `--` 側を採用した。
