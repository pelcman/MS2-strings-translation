# notes_qc — questdescription_final 欠落補完 1〜700行(ワーカーQ-C)

対象は 4 群:
1. **80000323〜80000421** 文字集めイベント/バレンタイン/キャンディ風船
2. **89000002〜89000339** 「今日のミッション」型デイリー(約 350 行)
3. **80020001〜80020196-Event-NA** レインボースライム/パンプキー/感謝祭/1周年/ハロウィン/

4. **89040001〜89050063** デイリー/イベントミッション(name=manual=complete がほぼ同文)

## 作業方法(次のワーカーへの申し送り)

1. **`work/missing/_qc_lookup.py <語> ...`** — jp/ko 全ファイルの同キー同フィールドを突合した
   KO→JA 対訳を部分一致検索するツールを作った。`python work/missing/_qc_lookup.py 미들턴` のように使う。
   **推測音写の前にこれを回すだけで大半の固有名詞が公式訳で埋まる。**
2. **`work/missing/_qc_match.py <開始行> <終了行>`** — `$xxx:ID$` をスロット化し数字を `#` に
   正規化した「テンプレート索引」で ko 全体を照合し、公式 JA テンプレートを提示する。
   1〜700 行で **167 行**がヒットし、そのまま文型を流用できた(結果は `_qc_hits.txt`)。
3. `_qc_show.py <キー接頭辞>` は questdescription_final の jp/ko/en を並べて表示する確認用。
4. 89000xxx 系は **89010/89020/89030/89050 の既訳が同一文型**なので、回数だけ差し替えれば済む。
   回数は **保持する**方針(notes_qa の 89010 系方針に統一)。

## 判断が分かれる点(次ワーカー/レビュー向け)

1. **文字集めクエスト 80000323 / 80000325 / 80000326**
   itemname の JA は 30000752〜30000761 が **と・き・め・き・の・メ・イ・プ・ル・2**
   (=「ときめきの」「メイプル2」)で、KO の 두・근・설・레・이・는・메・이・플・2 とは
   **区切り位置が 1 文字ずれている**。そのため KO のクエスト分割(두근두근 / 메이플2 / 사랑해요)と
   JA アイテム名を完全一致させられない。
   → 意味重視で **「ときめき」「メイプル2」「だいすき」** を採用した
   (80000326 は JA アイテム だ・い・す・き と完全一致する)。
   Q-B の 80000106〜109 では「アイテム名の連結」を優先しているので、方針を揃えるなら要再検討。
2. **89050xxx-Event-NA の name の粒度**
   jp 既訳は「回数を省いた EN 準拠の短い題(メイプルアーケード)」と
   「KO 準拠で回数を保持(黄金宝箱を5個見つける・フィールドボスを10回退治)」が混在している。
   多数派である **KO 準拠+回数保持** に統一した。
3. **89000021 manual の末尾 `|`** は KO 原文にそのまま存在する(complete には無い)ため保持した。
4. 原文の行末スペース(`확인할 수 있습니다. ⏎` `계획이다. ⏎` など)は既訳も保持する例が多いため
   **そのまま維持**した。
5. **89000258「전통 나무 시소」** は itemname 30000681 の公式訳が **サルのシーソー** なので
   そちらを採用(Q-B が 80000094 desc で使った「伝統の木のシーソー」とは不一致。要統一)。
